# v2.1.0

> 日期：2026-06-01
> 类型：Minor release

## Added

- 新增 `CacheHubStore`，可选接入 `cache-hub@^2.1.0` 的 Memory / Redis 原子状态后端。
- 支持 fixed-window、sliding-window、token-bucket、leaky-bucket 通过 cache-hub 状态原语执行。
- 新增 token-bucket 与 leaky-bucket 的 store rollback 快路径。
- 新增 CacheHubStore 单元测试与真实 Redis 集成测试。

## Changed

- CommonJS、ESM 与 TypeScript 类型入口同步导出 `CacheHubStore`。
- README、docs、API reference、storage guide、website 版本展示与 profile 同步更新。
- CI 增加 TypeScript 类型检查；覆盖率工具从 `nyc` 切换为支持 Node.js `>=18.0.0` 的 `c8`。

## Compatibility

- 现有 `MemoryStore` 与 `RedisStore` 保持兼容。
- `cache-hub` 作为 optional dependency 接入；只使用现有存储的用户无需修改代码。

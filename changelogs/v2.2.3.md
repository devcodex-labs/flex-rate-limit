# v2.2.3

> Date: 2026-06-11
> Type: Patch release

## Changed

- Upgraded the optional `cache-hub` dependency to `2.2.4` and aligned `CacheHubStore` with its public in-memory rate-limit cleanup API.
- Reworked the Rspress documentation site to use English as the default locale and Simplified Chinese under `/zh/`.
- Refreshed benchmark documentation with the 2026-06-11 local Memory, Redis, HTTP, and OSS comparison results.
- Clarified the project documentation policy: future English and Simplified Chinese user-facing docs must be updated together, with documented `skipReason` and follow-up plan for any intentional single-locale exception.
- Expanded the English documentation from summary-style pages into full parity user docs, including algorithms, API reference, business lock guidance, and allowlist scenarios.
- Added `npm run docs:validate` to catch Markdown link, anchor, stale docs path, and npm README package-boundary regressions before docs build/release checks.
- Refreshed top-level contribution, status, and security documents for the current `flex-rate-limit@2.2.3` project state and bilingual docs layout.

## Fixed

- Added TTL cleanup for auto-created in-memory `CacheHubStore` rate-limit primitives, preventing expired fixed-window, sliding-window, token-bucket, and leaky-bucket state from remaining in memory.
- Reworked `CacheHubStore` in-memory state cleanup to prune expired sliding-window entries without deleting still-active entries for the same key.
- Added ownership-aware `RedisStore.close()` and `RateLimiter.close()` so `store: 'redis://...'` clients can be shut down by the limiter while externally supplied Redis clients remain caller-owned by default.
- Changed public `RateLimiter.check()` results to omit hidden rollback metadata unless rollback tracking is explicitly requested by middleware or tests.
- Synchronized `2.2.3` version display across TypeScript definitions, docs index, and website navigation.
- Added English allowlist pages and sidebar navigation so all current Chinese user-facing pages have matching English routes.
- Registered middleware rollback response lifecycle listeners before `next()` so synchronous handlers are covered by `skipSuccessfulRequests` and `skipFailedRequests`.
- Replaced npm README links to unpacked `docs/**` and `examples/**` paths with stable documentation website and GitHub links.
- Fixed stale docs paths and hand-written table-of-contents anchors in the bilingual documentation set.

## Tests

- Added a dedicated `CacheHubStore` in-memory pressure regression that creates many short-lived keys across all four algorithms and asserts internal state is released after expiry.
- Added a targeted sliding-window regression that keeps active same-key entries after the oldest entry expires.
- Added middleware regression coverage for successful and failed responses that emit `finish` synchronously inside `next()`.

## Compatibility

- Public APIs remain compatible with `2.2.x`.
- Node.js support remains `>=18.0.0`.
- `cache-hub` remains optional; existing Memory and RedisStore users do not need to change code.

## Verification Notes

- Release verification must include `npm run docs:validate` in addition to `npm run docs:build`, because docs build alone does not prove hand-written anchors or npm README package-boundary links are valid.
